# 工银智汇通系统 Demo

工银智汇通企业国际汇款智能作业平台，包含产品封面、企业端、银行经办端、银行复核端和可信 AI 运行驾驶舱。

## 在线访问

GitHub Pages：<https://yeyufan04-glitch.github.io/gongyin-zhihuitong-demo/>

打开后先进入产品封面，点击“进入系统”进入原有企业端首页；系统内部的角色切换和业务演示逻辑继续保留。

## 下载运行

请下载仓库中的：

`工银智汇通系统Demo-封面版.zip`

解压后：

1. 双击 `index.html`；
2. 或运行 `启动预览.command`（macOS / Linux）；
3. Windows 使用 `启动预览.bat`。

网页包不需要 Node.js、npm、数据库、API Key 或 ChatGPT 账号。

## 演示边界

- SWIFT、银行风险系统和外部数据均为模拟演示数据；
- 原始单据扫描件仅用于竞赛演示证据；
- 不连接真实工行核心、SWIFT、海关或风险系统；
- AI只提供整理、比对和提示，不直接触发真实入账；
- 2019 案例保留题面金额与商业发票金额冲突，并进入待补件路径。
